# 파트너 (날개 크리보) 설계

작성일: 2026-10-02 · 상태: 구현됨 (본 스펙 4·6·7·8·9절에 합침)

구현 커밋에서 이 내용을 본 스펙(`2026-10-01-yugitokenbar-design.md`)의 4절(구조·저장), 6절(화면), 8절(테스트), 9절(범위 밖)에 합친다.

## 1. 목적

PokeTokenBar의 바탕화면 동료처럼, 토큰 사용 상태에 반응하는 **파트너** 「날개 크리보」를 바탕화면 떠 있는 창과 메뉴바 아이콘에 띄운다. 화면 문구는 "펫"이 아니라 "파트너"로 쓴다.

## 2. 해금

- 「날개 크리보」(cid 6314, 15번째 팩 『잃어버린 천년』 SR, GX 시대라 기본 시대 범위 안)를 1장 이상 가지면 해금된다.
- 해금은 영구다. 처음 가졌을 때 `GameState.partnerUnlocked = true`를 저장하고, 이후 팔거나 시대 범위를 바꿔도 유지된다.
- 검사는 `AppModel.save()` 직전(`Game.unlockPartnerIfOwned()`, 새로 해금되면 true)과 앱 시작 시 한 번. 팩·무료 카드·융합·가져오기 모두 save를 거치므로 따로 연결하지 않는다. 이미 가진 옛 세이브는 다음 시작 때 해금된다.
- 새로 해금되면 바탕화면 파트너가 나타나며 설렘 동작을 한 번 재생한다.
- 해금 전: 메뉴바는 지금의 카드 아이콘, 바탕화면 파트너 없음. 설정의 파트너 줄은 비활성이고 "「날개 크리보」 카드를 얻으면 파트너로 함께해요" 안내를 보인다.

## 3. 에셋

- `Resources/partner.png` — 날개 크리보 스프라이트 시트(1536×1872, RGBA, 사용자 제공, 개인용). `build-app.sh`가 `cards.json`처럼 `Contents/Resources/`로 복사하고, 찾는 순서도 `CardDB.bundled`와 같다(번들 → 저장소 `Resources/`).
- 격자: 셀 192×208, 8열 × 9행. 행 정의(행 번호는 0부터):

| 행 | 동작 | 프레임 |
|---|---|---|
| 0 | 대기·깜빡임 | 6 |
| 1 | 오른쪽 비행 | 8 |
| 2 | 왼쪽 비행 | 8 |
| 3 | 손짓 | 4 |
| 4 | 날갯짓(점프) | 5 |
| 5 | 시무룩 | 8 |
| 6 | 설렘 | 6 |
| 7 | 갸웃(머리 긁기) | 6 |
| 8 | 두리번 | 6 |

- 시작 시 `CGImage.cropping`으로 잘라 프레임을 캐시한다. 메뉴바용은 대기 행만 셀 위쪽 빈 공간을 잘라(y 50~207) 세로 가운데에 오게 하고 높이 18pt로 줄여, 오른쪽에 3pt 여백을 붙여 따로 캐시한다.

## 4. 동작

모든 동작은 5fps(프레임 간격 0.2초). 기준 상태는 매 갱신(60초)마다 다시 정하고, 한 번 재생 동작이 끝나면 기준 상태로 돌아간다.

### 기준 상태 (`PartnerMood.base(tokensPerMinute:limitPercent:)`, 위에서부터 먼저 맞는 것)

| 조건 | 동작 |
|---|---|
| Claude·Codex 공식 한도 중 가장 높은 % ≥ 80 | 시무룩(5) |
| 분당 토큰 ≥ 100,000 | 비행: 오른쪽(1)과 왼쪽(2)을 번갈아, 제자리 |
| 분당 토큰 ≥ 1,000 | 날갯짓(4) |
| 그 밖 | 대기: 깜빡임(0). 대기가 20~40초(무작위) 이어질 때마다 두리번(8) 1회 |

- 분당 토큰 = 직전 `refresh`와의 provider 합계 차이 ÷ 경과 분. 첫 갱신과 날짜가 바뀐 직후는 0으로 친다(음수는 0).
- 기준 동작은 한 바퀴 재생한 뒤 첫 프레임에서 무작위로 쉬고 다시 재생한다(대기 3~8초, 날갯짓 2~5초, 비행 1~3초, 시무룩 4~8초). 한 번 재생 동작이나 상태가 바뀌기 전의 동작이 끝나면 쉬지 않고 바로 다음으로 간다. 쉬는 중에 한 번 재생이 들어오거나 상태가 바뀌면 쉬기를 끝낸다.
- 기준값(80%, 100k, 1k, 쉬는 시간, 두리번 간격)은 `Partner.swift` 상단 상수에 둔다. 게임 밸런스가 아니므로 `Balance`에 넣지 않는다.

### 한 번 재생 (큐, 기준 상태를 잠시 덮는다)

| 사건 | 동작 |
|---|---|
| 파트너 클릭 | 갸웃(7) — 큐를 비우고 즉시 재생 |
| 팩·무료 카드 개봉에서 SR/UR가 나옴, 무료 팩 또는 무료 카드가 늘어남, 새로 해금 | 설렘(6) |
| 코인이 `Balance.packPrice` 미만 → 이상이 됨 | 손짓(3) |

같은 동작이 이미 큐에 있으면 다시 넣지 않는다.

### 메뉴바

- 해금 후 라벨의 SF Symbol 자리에 크리보 이미지(18pt), 코인·배지 글자는 그대로.
- 메뉴바는 대기 행만 쓴다. 4초마다 깜빡임 6프레임을 재생하고 나머지는 첫 프레임 정지(라벨을 다시 그리는 횟수를 줄이려고). 바탕화면 파트너를 꺼도 메뉴바 크리보는 남는다.

## 5. 바탕화면 파트너 (`UI/PartnerPanel.swift`)

- 테두리 없는 투명 `NSPanel`(`.nonactivatingPanel`, 레벨 `.floating`, `.canJoinAllSpaces`·`.fullScreenAuxiliary`, 그림자 없음), 내용은 SwiftUI `PartnerView`(현재 프레임 이미지)를 `NSHostingView` 하위 클래스에 담는다.
- 마우스: 누른 뒤 4pt 넘게 움직이면 창 드래그, 아니면 클릭. 클릭은 갸웃만 재생한다(MenuBarExtra(macOS 26)에는 창을 코드로 여는 API가 없고 상태바 버튼에 target/action이 없어 팝오버는 못 연다). 우클릭·Ctrl 클릭은 메뉴 [숨기기] → `partnerEnabled = false`.
- 위치는 드래그가 끝날 때 `GameState.partnerOrigin`에 저장. 저장 위치가 어느 화면에도 없으면(모니터 분리 등) 주 화면 오른쪽 아래(여백 24pt)로.
- 크기 `partnerSize`는 창 높이(pt), 폭은 192:208 비율.

## 6. 설정·저장

`GameState`에 추가(키 없으면 기본값, 옛 세이브 호환):

| 필드 | 기본 | 뜻 |
|---|---|---|
| `partnerUnlocked` | false | 해금 여부 (영구) |
| `partnerEnabled` | true | 바탕화면 파트너 보이기 |
| `partnerSize` | 128 | 높이 pt, 64~256, 16 단위 |
| `partnerOrigin` | nil | 바탕화면 창 위치 |

설정 "일반" 절: [바탕화면 파트너] 스위치와 [크기] 슬라이더(스위치가 꺼져 있으면 비활성). 해금 전에는 둘 다 비활성 + 2절의 안내 문구.

## 7. 파일

```
Sources/YugiTokenBar/
  Partner.swift          시트 자르기, PartnerAnim(행 표), PartnerMood.base, PartnerModel(현재 동작·프레임·큐·타이머)
  UI/PartnerPanel.swift  NSPanel 컨트롤러, 마우스 처리 호스팅 뷰, PartnerView
Resources/partner.png
```

`App.swift`(메뉴바 라벨), `AppModel.swift`(분당 토큰·사건 전달·해금 검사·패널 표시), `GameState.swift`, `Game.swift`(`unlockPartnerIfOwned`), `UI/SettingsView.swift`, `scripts/build-app.sh`를 고친다.

## 8. 테스트

- `PartnerMood.base`: 한도 > 사용량 > 대기 우선순위와 경계값(80%, 1k, 100k).
- 큐: 한 번 재생이 끝나면 기준 상태로 복귀, 클릭은 큐를 비우고 우선, 같은 동작 중복 방지.
- 시트: 셀 192×208, 행별 프레임 수, 잘린 프레임 크기.
- 해금: 6314를 가지면 해금되고 팔아도 유지, 새로 해금될 때만 true.
- `GameState`: 새 키가 없는 옛 세이브가 기본값으로 읽힌다.
- 분당 토큰: 첫 갱신·날짜 변경·감소 시 0.

## 9. 범위 밖

돌아다니기·커서 따라가기, 호버 말풍선, 저전력 모드 정지, 다른 파트너 선택, 메뉴바에서 기준 상태 동작 재생.
