# 유휴·컬렉션 스크롤 성능 Implementation Plan

> 역사 기록이고 현재 기준은 스펙(`docs/superpowers/specs/2026-10-01-yugitokenbar-design.md`)이다.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 아무것도 안 할 때의 CPU·깨우기를 거의 0으로, 컬렉션 셀의 흘러가는 이름이 창 전체를 매 프레임 다시 그리던 비용을 없애고, 매분 실패하는 Cursor API 호출을 막는다.

**Architecture:** 2026-10-12 측정(릴리스 .app, `YTB_STATE_DIR=$PWD/qa-state`) 기준. 유휴 CPU 1.9%·깨우기 724회/분의 98%가 파트너 5fps 타이머와 4초마다 메뉴바 깜빡임(프레임당 `NSStatusItem` 스냅샷 다시 그리기 약 10ms)이다. 컬렉션에서 긴 이름 카드에 마우스를 두면 `MarqueeText`의 repeatForever 애니메이션이 호스팅 뷰 전체를 매 프레임 레이아웃해 코어 26%를 쓴다. Cursor 대시보드 API는 번들 모드에서 매분 호출되며 404로 매번 실패한다. 세 가지 모두 작은 수정으로 막는다. Balance·게임 규칙·`Usage/`는 건드리지 않는다.

**Tech Stack:** Swift 6.2 / SwiftUI (macOS 26), Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-01-yugitokenbar-design.md` 4절(토큰 적립)·6절(메뉴바·파트너·개봉 화면·컬렉션 창)·8절(테스트 목록)을 각 작업에서 같이 고친다.

- 테스트는 `swift test --filter <Suite>`로 바뀐 스위트만 돌리고, 마지막 작업에서 `swift test` 전체.

## Review Focus

1. **해금됐지만 바탕화면 파트너가 꺼진 상태**: 메뉴바에 날개 크리보 아이콘은 남고 타이머는 돌지 않아야 한다 → 작업 1 `desktopOffStopsTimerButKeepsMenuIcon`.
2. **파트너를 다시 켜면** 타이머가 다시 돌고 바탕화면 창에 프레임이 나와야 한다(`updatePartner` 경로).

4. **Cursor API 백오프**: 실패(`isAuthoritative == false`) 뒤 `cursorAPIBackoff` 안의 `read`는 API를 부르지 않고 로컬만 읽고, 지나면 다시 부른다 → 작업 3 `cursorAPIBacksOffAfterFailure`.

```swift
    /// 바탕화면 파트너가 꺼져 있으면 타이머를 멈춘다. 메뉴바는 고정이라 깨울 일이 없다(유휴 CPU·깨우기의 거의 전부가 이 타이머와 깜빡임이었다).

        guard desktop else { stop(); return }

    }
```

## Task 3: Cursor 대시보드 API 실패 뒤 백오프

**Files:**
- Modify: `Sources/YugiTokenBar/TodayUsageReader.swift`
- Modify: `Tests/YugiTokenBarTests/UsageTests.swift`
- Modify: `docs/superpowers/specs/2026-10-01-yugitokenbar-design.md` 4절 토큰 적립 Cursor 문장, 8절 사용량 테스트 줄

**Why:** 번들 모드에서 60초 갱신마다 `CursorUsageAPI.fetchEntries`가 네트워크를 부르고 404로 실패한 뒤 로컬 `state.vscdb`로 떨어진다(캐시·백오프 없음, 로그 3줄/분). 실패하면 한동안 로컬만 읽는다.

**Steps:**

- [ ] `TodayUsageReader`에 다음을 더한다:

```swift
    /// 대시보드 API 가 실패하면(토큰 없음·HTTP 오류) 이만큼은 다시 부르지 않고 로컬 `state.vscdb`만 읽는다. 매분 실패하는 네트워크 호출을 막는다.
    static let cursorAPIBackoff: TimeInterval = 30 * 60
    private var cursorAPIRetryAt = Date.distantPast
    /// 대시보드 API 경로. 실앱·`PTB_PARITY=1`(`AppEnv.allowsLiveLimitsFetch`)에서만 있고, 테스트는 가짜를 넣는다.
    private let liveCursor: (@Sendable (Date) async -> LocalAdditionalUsageReader.CursorLoadResult)?

    init(claudeRoots: [URL]? = nil,
         liveCursor: (@Sendable (Date) async -> LocalAdditionalUsageReader.CursorLoadResult)? =
            AppEnv.allowsLiveLimitsFetch ? { await LocalAdditionalUsageReader.cursorEntriesAsync(modifiedSince: $0) } : nil) {
        self.claudeRoots = claudeRoots
        self.liveCursor = liveCursor
    }

    /// Cursor: 대시보드 API 가 있으면 그것, 실패(`isAuthoritative == false`)하면 `cursorAPIBackoff` 동안 로컬만.
    func cursorEntries(modifiedSince start: Date, now: Date) async -> [LocalUsageReader.Entry] {
        guard let liveCursor, now >= cursorAPIRetryAt else {
            return LocalAdditionalUsageReader.cursorEntries(modifiedSince: start).entries
        }
        let result = await liveCursor(start)
        if !result.isAuthoritative { cursorAPIRetryAt = now.addingTimeInterval(Self.cursorAPIBackoff) }
        return result.entries
    }
```

  `read(since:now:)`의 `let cursor = AppEnv.allowsLiveLimitsFetch ? ... : ...` 세 줄을 `let cursor = await cursorEntries(modifiedSince: start, now: now)`로 바꾼다. 파일 머리 doc 주석에 "Cursor 대시보드 API는 실패하면 30분 백오프" 한 줄을 더한다.

- [ ] `UsageTests.swift`에 테스트를 더한다:

```swift
    /// Cursor API 가 실패하면 백오프 동안 다시 부르지 않고 로컬만 읽고, 지나면 다시 부른다
    @Test func cursorAPIBacksOffAfterFailure() async {
        actor Calls { var n = 0; func bump() { n += 1 } }
        let calls = Calls()
```
