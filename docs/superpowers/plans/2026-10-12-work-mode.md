## Task 1 — 모델·캐시·환경값·파트너·테스트

- `Sources/YugiTokenBar/AppModel.swift`: `static let workModeKey = "workMode"`. 저장 프로퍼티
  `var workMode = UserDefaults.standard.bool(forKey: AppModel.workModeKey) { didSet { UserDefaults.standard.set(workMode, forKey: Self.workModeKey); updatePartner() } }`
  (세이브 `GameState`에는 넣지 않는다). `updatePartner()`의 첫 guard에 `!workMode`를 더해 켜져 있으면 바탕화면 창을 숨긴다(`partnerEnabled`는 그대로).
- `Sources/YugiTokenBar/ImageCache.swift`: init에 `defaults: UserDefaults = .standard`를 더하고 보관. 켜져 있으면(`defaults.bool(forKey: AppModel.workModeKey)`)
  `cached`·`cachedPack`·private `image(key:url:maxPixels:)`가 디스크·네트워크·디코드 없이 바로 nil (세 군데 guard 한 줄씩). 메모리 캐시는 비우지 않는다.
- `Sources/YugiTokenBar/UI/CardImageView.swift`의 `extension EnvironmentValues`에 `@Entry var workMode = false`를 `animationsOff` 옆에 추가.
- `Sources/YugiTokenBar/App.swift`: 두 scene(`PopoverView`·`DexView`)에 `.environment(\.workMode, model.workMode)`를 `animationsOff` 옆에 넣는다.
  `MenuBarLabel(... unlocked: model.game.state.partnerUnlocked && !model.workMode ...)` → 켜지면 기본 SF Symbol 카드 아이콘.
- 테스트 `Tests/YugiTokenBarTests/ImageCacheTests.swift`에 하나: `UserDefaults(suiteName: "ytb-test-\(UUID())")`에 `workMode = true`로 두고
  로더가 불렸는지 기록하는 `ImageCache(dir: tempDir(), loader:, defaults:)`를 만들어 `image(1, size: .small)`이 nil이고 로더가 안 불렸음을, 같은 defaults를 false로 바꾸면 로드됨을 확인.
  (`packImage`도 같은 테스트 안에서 한 줄로 같이 봐도 좋다.)
- 끝나면 `swift test` 통과. 커밋 1개.

## Task 2 — 뷰 분기·연출·설정 스위치·문구

모두 `@Environment(\.workMode)`로 읽는다. 등급 색·고유 색은 쓰지 않고 `.fill`·`.secondary`·`.tertiary`만.

- `Sources/YugiTokenBar/UI/CardImageView.swift`
  - private `CardPlaceholder(name:owned:)`: `RoundedRectangle(cornerRadius: 7).fill(.fill.tertiary)` 위에 가운데 정렬한 9pt `.medium` 카드 이름(여러 줄, 가로 4·세로 3 패딩), 글자색 보유 `.secondary`·미보유 `.tertiary`. 이름이 비어 있으면 사각형만.
  - `CardImageView`: 켜지면 `CardPlaceholder`를 그린다(바깥 `aspectRatio`·`clipShape`·`cardRim` 테두리는 그대로 두어 크기·모서리가 안 변하게). `.task(id:)`의 id를 `Int?`로 바꿔 켜지면 nil(로딩 task 자체를 돌리지 않는다), 몸체 첫 줄에 `guard !workMode`. 미보유 흑백 처리는 이미지 쪽에만 남긴다.
  - `CardBack`: 켜지면 `CardPlaceholder(name:)`만(뒷면 이미지·그라데이션·`glow` 그림자 없음).
  - `PackImageView`: 켜지면 같은 0.53 칸을 `Color.clear.overlay(.fill.tertiary)`처럼 `.fill`로만 채우고 task id는 nil(이름은 옆에 있으니 쓰지 않는다).
  - `CardTilt`: `@Environment(\.workMode)`를 읽어 몸체 첫 줄에서 `let enabled = enabled && !workMode`로 기울기·반사·홀로그램을 끈다.
- `Sources/YugiTokenBar/UI/PackOpenView.swift`
  - `RareEffect`: `if tier < 3 || workMode { content }` (섬광·광택 스윕·포일·빛 테두리·빛 점·숨쉬기 전부 생략).
  - `FlipCard`: R 그림자 `.shadow(color: pull.tier == 2 ? Rarity.color(tier: 2) : .clear ...)`를 켜지면 `.clear`.
- `Sources/YugiTokenBar/UI/SettingsView.swift` 일반 섹션, [언어] 줄 아래:
  `toggleRow("업무 모드", hint: "카드·팩 이미지와 파트너를 숨기고 밋밋한 상자만 보여요", isOn: Bindable(model).workMode)`.
- 문구: `python3 tools/sync-strings.py`로 en/ja에 키를 붙인 뒤 번역을 채운다. en `"업무 모드" = "Work mode"`, ja `"仕事モード"`;
  설명 en `"Hides card and pack images and the partner, showing plain boxes instead"`, ja `"カードとパックの画像、パートナーを隠して無地の箱だけを表示します"`. `python3 tools/sync-strings.py --check` 통과.
- `swift build` 통과, `swift test` 통과. 커밋 1개.
